# Extended Brand Colour Palette

Displays extended brand colour palette for charting

## Usage

``` r
show_extended_palette()
```

## Value

a Base R plot object

## Examples

``` r
library(scales)
library(SangerTools)
show_extended_palette()

#>  [1] "#9880BB" "#0061BA" "#3BBCD9" "#223873" "#71B72B" "#D585BA" "#007761"
#>  [8] "#4D8076" "#00C9A7" "#4A4453" "#C27767" "#D5CABD"
```
