# Brand Colour Palette

Displays a brand colour palette for showing the hex codes associated
with brand

## Usage

``` r
show_brand_palette()
```

## Value

a Base R plot object

## Examples

``` r
library(scales)
library(SangerTools)
show_brand_palette()

#> [1] "#9880BB" "#0061BA" "#3BBCD9" "#223873" "#71B72B"
```
